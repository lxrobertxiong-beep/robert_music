## 填写示例（节选）

以下为**虚构示例**，演示口吻与粒度，请勿当作真实变更记录。

```markdown
## v0.4.0 — 2026-11-02

**版本号**：v0.4.0  
**发布日期**：2026-11-02（Asia/Shanghai）  
**对应标签 / commit**：v0.4.0 / abcdef0  

### 亮点

- 通话降噪在低信噪比公交场景下语音保留更稳，主观听感毛刺减少。
- 新增开放式耳机漏音抑制的实验性预设，便于与试听补偿联动验证。
- 3D 空间音效默认 HRTF 切换延迟降低，利于游戏与影音实时路径。

### 新增

- `leakage` 模块实验预设与示例配置（文档见 docs/…）。
- 评测脚本支持按耳机型号分组导出 CSV。

### 改进

- AI 低频补偿在小音量下的动态增益曲线更平滑。
- 三频均衡动态补偿与通话路径的参数互斥说明写入 CONTRIBUTING 相关章节。

### 修复

- 修复特定采样率下空间音效右声道偶发静音（#128）。
- 修复文档中试听补偿输入电平单位不一致的问题。

### 已知问题

- 漏音实验预设在部分 DSP 上尚未完成周期与内存标测。
- 新评测 CSV 列名可能在下个次版本微调。

### 升级注意

- 默认降噪强度参数有微调；若产品侧写死旧默认值，请对照迁移表更新。
- 需同步更新模型文件目录中的 `*.bin`（见发布附件）。

### 贡献者致谢

感谢 @alice、@bob、@carol 以及参与听感盲测的评测同学。
```
